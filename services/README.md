# Services

Интеграции Sprint 6 разделены и заменяемы:

- `storage/` — приватное файловое хранилище;
- `preprocess/` — подготовка изображения; MVP сохраняет исходные байты;
- `ocr/` — локальный Tesseract с контролируемым fallback;
- `judge/` — консервативный структурный скоринг;
- `review/` — confidence и решение о ручной проверке.

Web и worker зависят только от контрактов адаптеров. Замена OCR или judge на внешнюю модель не
требует менять Submission/Evaluation API.
