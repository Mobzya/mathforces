# Sprint 5 — админ-панель и конструктор контеста

## Результат

Администратор получает отдельный защищённый раздел `/admin` с обзором платформы, конструктором
контестов, модерацией посылок, управлением организациями и пользователями, а также журналом
действий.

## Экраны

- `/admin` — реальные счётчики, последние контесты и действия;
- `/admin/contests` — список и создание контеста;
- `/admin/contests/[id]` — параметры тура, редактор пяти задач и rubric;
- `/admin/submissions` — фильтры, защищённое фото, баллы и перепроверка;
- `/admin/organizations` — создание и переименование;
- `/admin/users` — поиск, роль и текущая организация;
- `/admin/logs` — хронология административных операций.

Все страницы защищены серверным layout. Пользователь без сессии перенаправляется на вход, участник
без роли `ADMIN` — в собственный профиль.

## Аудит

Таблица `AdminAction` хранит автора, тип действия, сущность, краткое описание, структурированные
детали и время. Создание и изменение контеста, задачи, посылки, пользователя и организации пишутся
транзакционно вместе с основным изменением.

Удаление администратора не удаляет историю: поле автора становится `NULL`. Секреты, пароли и
содержимое фотографий в журнал не записываются.

## API

| Метод       | Маршрут                               | Назначение                 |
| ----------- | ------------------------------------- | -------------------------- |
| `GET/POST`  | `/api/admin/contests`                 | список и создание          |
| `GET/PATCH` | `/api/admin/contests/[id]`            | просмотр и параметры       |
| `POST`      | `/api/admin/contests/[id]/publish`    | запуск после пяти задач    |
| `GET`       | `/api/admin/submissions`              | все посылки с фильтрами    |
| `PATCH`     | `/api/admin/submissions/[id]/score`   | баллы, статус, комментарий |
| `POST`      | `/api/admin/submissions/[id]/rejudge` | возврат в очередь          |
| `GET/POST`  | `/api/admin/organizations`            | список и создание          |
| `PATCH`     | `/api/admin/organizations/[id]`       | переименование             |
| `GET`       | `/api/admin/users`                    | список и поиск             |
| `PATCH`     | `/api/admin/users/[id]`               | роль и организация         |
| `GET`       | `/api/admin/logs`                     | последние 300 действий     |

Общие API контестов, задач и посылок сохранены для обратной совместимости и используют те же
проверки прав и аудит.

## Ограничения

- запуск разрешён только при наличии ровно пяти задач;
- после запуска условия и rubric заблокированы от изменения;
- балл ограничен максимумом задачи;
- нельзя снять роль администратора с собственной текущей сессии;
- повторная проверка возвращает посылку в `QUEUED` и снимает финальный балл, сохраняя предыдущий
  предварительный результат до работы worker;
- фактическая автоматическая перепроверка относится к Sprint 6.

## Проверка

1. Войти аккаунтом с ролью `ADMIN`.
2. Создать контест и заполнить пять задач с критериями.
3. Запустить контест и открыть его публичную страницу.
4. В разделе посылок сохранить балл и запустить перепроверку.
5. Изменить организацию или тестового пользователя.
6. Убедиться, что каждое действие появилось в `/admin/logs`.
