# Sprint 2 — контесты и задачи

## Результат

Платформа хранит контесты в PostgreSQL, показывает доступные пользователю туры, открывает страницу с
задачами и позволяет зарегистрироваться на незавершённый контест.

## Таблицы

- `Contest` — название, описание, правила, теги, тайминг, статус, видимость, организация и
  создатель;
- `Problem` — условие, тема, баллы, decay, порядок и закрытая rubric;
- `ContestRegistration` — уникальная регистрация пользователя на контест.

Стандартный тур ограничен пятью задачами. Запустить или завершить контест без пяти задач нельзя.

## Статусы

- `ANNOUNCED` — контест виден, но публичный API скрывает названия и условия;
- `RUNNING` — задачи открыты, регистрация ещё возможна;
- `FINISHED` — регистрация закрыта, задачи остаются доступны.

Статус хранится явно и управляется организатором. Автоматические переходы по времени будут добавлены
вместе с worker-задачами.

## API

| Метод   | Маршрут                       | Назначение                               |
| ------- | ----------------------------- | ---------------------------------------- |
| `GET`   | `/api/contests`               | доступные контесты                       |
| `GET`   | `/api/contests/[id]`          | контест и публичные данные задач         |
| `POST`  | `/api/contests`               | создать контест, только admin            |
| `PATCH` | `/api/contests/[id]`          | изменить статус/настройки, только admin  |
| `POST`  | `/api/contests/[id]/problems` | добавить задачу, только admin            |
| `PATCH` | `/api/problems/[id]`          | изменить задачу до запуска, только admin |
| `POST`  | `/api/contests/[id]/register` | зарегистрировать пользователя            |

Приватный контест доступен администратору и участникам связанной организации. Rubric никогда не
попадает в публичный контракт задачи.

## Исправление рейтинга

До первого рейтингового контеста `currentRating` и `maxRating` равны `0`, а UI показывает `—` и
звание «Без рейтинга». Отдельная data migration обнуляет прежние стартовые значения 500.
