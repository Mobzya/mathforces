# Политика безопасности

## Поддерживаемая версия

Пока проект находится на стадии MVP, исправления безопасности выпускаются только для актуального
состояния ветки `main`.

## Как сообщить об уязвимости

Не публикуйте эксплойт, персональные данные или секреты в обычном Issue. Используйте приватный
GitHub Security Advisory репозитория либо свяжитесь с владельцем `Mobzya` через приватный канал.

В сообщении укажите:

- затронутый маршрут или компонент;
- необходимые права пользователя;
- минимальные шаги воспроизведения;
- возможное влияние;
- безопасный пример без чужих данных.

## Что нельзя публиковать

- `.env` и API-ключи;
- session cookie, токены сброса пароля и хеши;
- дампы PostgreSQL;
- содержимое `storage/submissions`;
- реальные решения, почту и иные персональные данные участников.

## Эксплуатационные ограничения

`npm run dev:lan` предназначен только для доверенной локальной сети. Для интернета требуются HTTPS,
reverse proxy, off-host backup, централизованные секреты и внешнее приватное хранилище файлов.
