# Workers

`judge-worker/` выбирает из PostgreSQL старейшую посылку `QUEUED`, атомарно переводит её в
`PROCESSING` и запускает pipeline Sprint 6.

Запуск:

- `npm run worker:judge` — непрерывная обработка очереди;
- `npm run worker:judge:once` — одна запись или безопасный выход при пустой очереди.

Web-приложение после загрузки только создаёт durable job и сразу отвечает пользователю. PostgreSQL
остаётся источником истины, а постоянно запущенный worker обрабатывает очередь, автоматически
запускает готовые контесты по расписанию и завершает просроченные туры.

Локальная OCR/эвристическая оценка всегда требует ручного подтверждения финального балла. Это
намеренная защита: структурные признаки текста не доказывают математическую корректность и не должны
автоматически менять рейтинг реального соревнования.
